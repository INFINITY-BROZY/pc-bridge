How custom sites work

  1. Add the site here or in the dashboard. This tells the local server it may accept requests from that origin.
  2. Grant access once. Chrome asks you to allow the extension on that one site. Nothing is granted globally.
  3. Open the chat and click the PC Bridge icon. The floating panel appears. If the site's markup is unusual, use the panel's Advanced → selectors fields.
  4. Revoke anytime. Remove browser access below or remove the site in the dashboard. The server token still protects every request.
