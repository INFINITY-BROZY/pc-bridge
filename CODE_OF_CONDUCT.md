# Code of conduct

## Our pledge

We want PC Bridge to be a welcoming project for anyone who wants to connect AI
chats to their own computer safely. We pledge to make participation harassment-free
for everyone, regardless of experience, identity, background, or tool preference.

## Expected behavior

- Be direct, kind, and constructive.
- Assume good intent; ask before assuming malice.
- Respect differing threat models and operating systems.
- Do not pressure anyone to run code they do not understand.
- Do not post tokens, private paths, personal data, or command output that
  contains secrets.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Sharing someone else's token, credentials, or private files.
- Encouraging use of PC Bridge to access systems without authorization.
- Deliberately weakening security controls in a contribution.
- Publishing exploit details before a fix is available.

## Enforcement

Maintainers may edit, remove, or reject contributions that violate this policy,
and may block repeat offenders. Reports can be sent privately to the repository
maintainers via GitHub.

This policy is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
